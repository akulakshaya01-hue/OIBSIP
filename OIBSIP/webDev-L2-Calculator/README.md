# Calcura — Modern Calculator

A modern, responsive browser calculator developed as part of my **Oasis Infobyte Web Development & Designing Internship — Level 2**.

Calcura is designed to provide a clean and user-friendly calculation experience while supporting common arithmetic operations, percentage calculations, calculation history, keyboard controls, and customizable themes.

## ✨ Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Decimal number support
- Percentage calculations
- Operator chaining
- Calculation precedence
- Backspace functionality
- Clear/AC functionality
- Division-by-zero error handling
- Calculation history
- Clear History option
- Click previous calculations to reuse their results
- Light and Dark theme
- Theme preference saved using localStorage
- Calculation history saved using localStorage
- Keyboard support
- Responsive design for desktop and mobile devices
- No use of `eval()`
- Accessible button interactions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
