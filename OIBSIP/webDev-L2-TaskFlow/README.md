# TaskFlow — Smart To-Do Web App

TaskFlow is a modern, responsive task management web application created as part of the Oasis Infobyte Web Development & Designing Internship — Level 2.

The application provides a clean workspace for creating, organizing, completing, editing, and deleting daily tasks.

---

## ✨ Features

- Add new tasks
- View all tasks
- View pending tasks
- View completed tasks
- Mark tasks as completed
- Move completed tasks back to pending
- Edit tasks
- Delete tasks
- Clear all completed tasks
- Pending task counter
- Completed task counter
- Total task counter
- Completion percentage
- Progress bar
- Empty-state messages
- Task creation timestamps
- LocalStorage persistence
- Responsive design
- Keyboard-friendly edit modal
- Modern desktop and mobile interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage
- Google Fonts

No backend or external JavaScript framework is required.
