# Tempora – Temperature Converter

A modern and responsive temperature conversion website developed as part of the Oasis Infobyte Web Development and Designing Internship.

## Level 1 – Task 3

### Features

- Convert temperatures between Celsius, Fahrenheit, and Kelvin
- Numeric input validation
- Absolute-zero validation
- Displays all three temperature units simultaneously
- Responsive design for desktop, tablet, and mobile
- Clean and modern user interface
- Press Enter to perform conversion

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Temperature Formulas

### Celsius to Fahrenheit
°F = (°C × 9/5) + 32

### Fahrenheit to Celsius
°C = (°F − 32) × 5/9

### Celsius to Kelvin
K = °C + 273.15

### Kelvin to Celsius
°C = K − 273.15
