# Legacy — Tribute Experience

A visually engaging tribute webpage dedicated to **Dr. A. P. J. Abdul Kalam**, created as part of the **Oasis Infobyte Web Development & Designing Internship — Level 2**.

The project presents his life, scientific contributions, presidency, achievements and lasting influence through a responsive editorial-style interface.

## ✨ Features

- Premium editorial-inspired design
- Responsive layout
- Dr. A. P. J. Abdul Kalam biography
- Major life milestones timeline
- Achievement cards
- Tribute quote section
- Legacy section
- Smooth scrolling navigation
- Scroll reveal animations
- Active navigation highlighting
- Mobile-friendly layout
- Royalty-free Wikimedia Commons image

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Wikimedia Commons
