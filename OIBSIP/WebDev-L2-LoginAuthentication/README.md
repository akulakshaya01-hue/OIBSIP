# SecureGate — Login Authentication System

A modern and responsive client-side authentication interface built with HTML5, CSS3, and Vanilla JavaScript.

SecureGate provides a clean authentication experience with user registration, login validation, password protection, session management, and a protected dashboard.

## ✨ Features

- User registration with full name, email, and password
- Password validation
  - Minimum 8 characters
  - At least one number
- Duplicate account detection
- Secure password hashing using SHA-256
- Login authentication
- Generic incorrect-credential error message
- Password visibility toggle
- Client-side session management
- Protected dashboard after successful login
- Logout functionality
- Responsive design for desktop and mobile devices
- Data persistence using browser localStorage
- Form validation and user-friendly error messages

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Web Crypto API
- localStorage
